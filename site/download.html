Install

Steps for the installer you downloaded.

  1. 01

    Run Tween_0.1.0_x64-setup.exe.

  2. 02

    If SmartScreen says “Windows protected your PC”, click “More info”, then “Run anyway”.

  3. 03

    Open Tween. First-run setup checks your GPU and downloads the RIFE models and FFmpeg (a few hundred MB).

  4. 04

    The streaming engine needs the Microsoft Visual C++ 2015-2022 x64 runtime. Without it Tween uses file mode automatically.

  1. 01

    Open the .dmg and drag Tween to Applications.

  2. 02

    The app isn’t notarized yet: right-click Tween → Open → Open, or run:

    xattr -dr com.apple.quarantine /Applications/Tween.app
  3. 03

    First-run setup downloads the models and FFmpeg.

  1. 01

    AppImage:

    chmod +x Tween_0.1.0_amd64.AppImage && ./Tween_0.1.0_amd64.AppImage
  2. 02

    deb:

    sudo apt install ./Tween_0.1.0_amd64.deb
  3. 03

    Requires Vulkan drivers (mesa-vulkan-drivers or your GPU vendor’s driver).
